A few good questions.

What Mac do I need?

An Apple Silicon Mac running macOS Tahoe 26 or later.

Are all hardware readings available?

Readings depend on your hardware and macOS permissions. The sandboxed TestFlight build may have different sensor access from the direct download.

How do I update?

Install a newer stable DMG, or run brew upgrade --cask mac-gauge if you installed through Homebrew.

Can I join TestFlight?

Internal testing is by invitation. There is no public TestFlight invitation yet.

Is there an Intel, Windows or Linux version?

This distribution is built for Apple Silicon Macs.
