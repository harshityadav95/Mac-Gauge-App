# Mac Gauge

System monitoring for the macOS menu bar. Requires Apple Silicon and macOS 26 or later.

Website: https://harshityadav.in/Mac-Gauge-App/

Signed and notarized downloads are published under Releases. Stable production releases update `solvePao/tap/mac-gauge`.

## TestFlight

Internal testing is by invitation. No public invitation is currently available.

## Updates

Download a newer stable DMG or run `brew upgrade --cask mac-gauge`.
